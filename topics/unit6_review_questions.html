LIU08106 / RIU08106 · Unit 06

Review Questions and Exercises

Use complete sentences, calculations with units, and authentic BLISS/BRIM examples.

← Back to Unit 6 on the course site

Foundations

  1. Explain why one information resource might need both a controlled source and an access derivative.
  2. Define a file format, filename extension, codec and container with a different example for each.
  3. Explain why changing a file extension does not convert an image or video.
  4. Distinguish a MIME type from a codec.
  5. Use one MP4 example to show how a container may hold video and audio codecs.
  6. Compare PNG, JPEG, TIFF and SVG for diagrams, photographs and scanned records.
  7. Explain a suitable reason to offer both WAV and MP3 versions of a spoken resource.
  8. What extra information would you need to evaluate a video labelled only video.mp4?

Compression and quality

  1. Explain lossless compression, giving an audio and an image example.
  2. Explain lossy compression and identify three possible artifacts affecting user understanding.
  3. Why can a lossless file still be an unsuitable preservation master?
  4. A source is 80 MB and an access copy is 20 MB. Calculate the compression ratio and percentage saving.
  5. A file shrinks from 120 MB to 45 MB. Calculate its reduction percentage to two decimal places.
  6. Why is a compression ratio not evidence that an image preserves every important detail?
  7. Explain why repeated lossy re-encoding should normally be avoided.
  8. Outline a fair same-source image quality comparison.

Storage, bitrate and bandwidth

  1. Distinguish 8 Mb from 8 MB and 1 MB from 1 MiB.
  2. Estimate raw storage (decimal MB) for a 2000 × 1500 24-bpp packed raster image.
  3. Estimate raw storage for 90 seconds of 44.1 kHz, 16-bit, mono PCM audio.
  4. Establish a formula for compressed audio file size from bitrate and duration.
  5. A 5-minute audio file has average bitrate 128 kb/s. Estimate its size in decimal MB.
  6. A clip contains 2 Mb/s video and 128 kb/s audio for 150 seconds. Estimate file size in MB.
  7. Estimate ideal transfer time for a 36 MB file using 1.5 Mb/s throughput.
  8. Why do real downloads take longer than ideal estimates? State three reasons.

Applied decision-making

  1. Compare progressive download with adaptive streaming for a small learning website.
  2. What should a format-decision matrix include for a digitised poster?
  3. Write a naming convention linking a preserved source, a working copy and an access copy.
  4. Propose eight fields for a file manifest and state how a checksum contributes to quality control.
  5. BLISS scenario: choose files for a 3-minute catalogue video intended for students with limited data.
  6. BRIM scenario: describe how to deliver an authorised oral-history excerpt while protecting provenance and permissions.
  7. Explain how captions, transcripts and explicit file sizes improve multimedia access.
  8. Create a six-step final export and release checklist for an institutional multimedia collection.
Revision guidance: For calculations, state assumptions and label MB, MiB, Mb/s, bytes and seconds carefully. In case questions, justify choices using real information needs, institutional source control, rights and user access. These are practice questions, not an official examination.
