LIU08106 / RIU08106 · Unit 02

Review Questions & Applied Exercises

Explain the concepts, work through calculations and defend your visual design decisions.

Part A — Definitions and explanation

  1. Explain the difference between digital media fundamentals and visual communication. Why do both matter in an information service?
  2. Define a pixel and a raster image. What is meant by pixel dimensions?
  3. Distinguish raster and vector graphics. Give two suitable uses and one limitation for each.
  4. Explain the difference among pixel dimensions, pixel count, PPI and printer DPI.
  5. Why does changing a file's PPI metadata not necessarily add image detail?
  6. Define aspect ratio. Explain how cropping, stretching, downsampling and upsampling differ.
  7. Compare RGB, CMYK and grayscale representations and identify appropriate contexts of use.
  8. Explain the terms bit depth, colour channel, colour space and colour profile.
  9. Describe five visual-design principles and give one example of each.
  10. What is visual hierarchy? How can typography, spacing and alignment support it?

Part B — Quantitative and technical practice

  1. Find the total pixel count, in megapixels, of an image measuring 3000 × 2000 pixels. Show your working.
  2. A 2400-pixel-wide image is prepared for printing at 300 PPI. Estimate the intended width in inches and centimetres. Explain one reason why the result does not guarantee print quality.
  3. An image measures 1600 × 1200 pixels and uses 24 bits per pixel. Estimate its uncompressed pixel data size in bytes and MiB. Explain why the actual saved file may differ.
  4. Why is 24-bit RGB often described as 8 bits per channel? How many possible values can each channel represent?
  5. An archival image is 1200 × 800 pixels. It is stretched to fit a 1000 × 1000-pixel square. Explain what happens to its aspect ratio and propose a better approach.
  6. A student claims that a JPEG file and a TIFF file of the same source must have identical file sizes. Critically assess the claim.

Part C — Design and accessibility

  1. Compare a poorly designed poster containing five font families, dense centred paragraphs and weak contrast with a well-structured alternative. Give four specific improvements.
  2. Explain why colour should not be the only means of communicating status. Provide a concrete example relevant to a digital collection.
  3. Describe the WCAG 2.2 Level AA minimum contrast targets for ordinary text and qualifying large text, noting that exceptions apply.
  4. Propose a reading order for a public-information poster. Justify the order and identify the most important content.
  5. Explain how responsive layout may change the arrangement of a three-column image gallery on a mobile phone.

Part D — Professional cases

BLISS

22. The library wants a digital poster announcing research-training sessions. Design a hierarchy for the title, time, venue, intended audience and registration instructions. Specify two suitable visual assets and two accessibility checks.

23. A digital catalogue needs a scalable library-direction icon and 30 photographic book covers. Recommend raster/vector choices for each and explain why.

BRIM

24. A records office has a 2400 × 1600 pixel scan of a historical document. Outline how to create a smaller online access image without replacing or misrepresenting the source master. Include caption and versioning decisions.

25. A virtual exhibition displays photographs with edited brightness and cropped borders. Explain how to make these derivatives usable without misleading researchers about the originals.

Part E — Short design brief

26. Create a one-page design specification for an information graphic in your chosen professional field. Include audience, task, pixel dimensions or intended print size, raster/vector asset choices, colour strategy, two type styles, layout hierarchy and a checklist for quality and accessibility.

Self-check pointers

Technical definitions (1–10)

Separate representation (raster/vector and RGB/CMYK), density (PPI/DPI) and arrangement (typography/hierarchy). Explain what each changes and what it does not change.

Calculations (11–16)

Pixel count = width × height. Print width in inches = pixels ÷ PPI. Approximate uncompressed pixel bytes = width × height × bits per pixel ÷ 8. For MiB, divide bytes by 1,048,576. Preserve image aspect ratio.

Design and scenarios (17–26)

Start with audience and information purpose. Check visual hierarchy, legibility, data/bandwidth, rights and accessibility. In BRIM cases, distinguish a derivative from the source/master and document alterations.

These are formative study questions, not a published institutional examination.
