Multimedia concepts: a beginner's glossary

Short definitions connected to each of the 12 course units.

Many multimedia terms sound similar but describe different ideas. This glossary gives everyday explanations. The full notes show how the terms work in real library and archives services.

Return to course home

Unit 1: Introduction to Multimedia

Medium
a way of representing information, such as text, sound or a picture.
Multimedia
a purposeful combination of at least two media forms.
Interaction
an action by the user, such as choosing a link or playing audio.
Access
the ability to find and use information in an appropriate form.

Unit 2: Digital Media and Visual Communication

Pixel
one picture element in a raster image grid.
Raster image
a picture represented by a grid of pixels.
Vector graphic
a graphic represented through shapes, paths and mathematical descriptions.
Contrast
the difference in brightness or colour that helps distinguish content.

Read the Unit 2 notes

Unit 3: Digital Images and Image Editing

Capture
creating a digital image from a physical or visual source.
Master
a carefully retained source-quality digital version.
Derivative
another version made for a specific use, such as web viewing.
OCR
software that attempts to recognise text within images.

Read the Unit 3 notes

Unit 4: Audio in Multimedia Systems

Sound wave
a changing vibration that can be recorded.
Sample rate
the number of audio measurements taken each second.
Bit depth
the number of bits used to represent a sample in uncompressed digital audio.
Transcript
a written representation of spoken words and relevant sounds.

Read the Unit 4 notes

Unit 5: Video, Animation and Storytelling

Frame
a single image within moving video.
Frame rate
how many frames are displayed each second.
Storyboard
a scene-by-scene visual plan of the message.
Caption
synchronised text representing speech and important sounds.

Read the Unit 5 notes

Unit 6: Formats, Compression and Delivery

File format
a specification for how digital information is arranged and stored.
Compression
representing data with fewer bits.
Lossy compression
size reduction that discards some information.
Bitrate
the amount of encoded media data used per second.

Read the Unit 6 notes

Unit 7: Authoring and Hypermedia

Authoring
combining media and controls into a usable information experience.
Hypertext
linked pieces of text or information.
Hypermedia
linked content that can include text, images, audio and video.
Sitemap
a diagram of pages or screens and their relationships.

Read the Unit 7 notes

Unit 8: Digitisation and Quality Control

Digitisation
creating digital representations of analogue originals.
Surrogate
a digital representation used instead of directly handling an original.
Quality assurance (QA)
planned methods for preventing quality problems.
Quality control (QC)
checks used to find problems in completed outputs.

Read the Unit 8 notes

Unit 9: Metadata and Retrieval

Metadata
structured information describing or managing another information resource.
Identifier
a stable code or value used to distinguish an item.
Controlled vocabulary
an agreed set of terms used consistently for description.
Provenance
information about the source and history of an item.

Read the Unit 9 notes

Unit 10: Preservation and Security

Digital preservation
ongoing actions that keep digital material usable and trustworthy.
Backup
a separate copy intended to support recovery.
Fixity
evidence that recorded bits have or have not changed.
Restore test
a practical check that a saved copy can actually be recovered and opened.

Read the Unit 10 notes

Unit 11: Legal and Inclusive Practice

Copyright
legal protection for qualifying original expression.
Licence
permission to use a work under stated conditions.
Personal data
information concerning an identified or identifiable person.
Accessibility
design that lets people with different abilities use information.

Read the Unit 11 notes

Unit 12: Publishing and Evaluation

Publishing
making a resource available to its intended audience.
Usability
how effectively and easily users can complete tasks.
Evaluation
collecting evidence about whether a resource meets its goals.
Release readiness
the documented result of checking a product before publication.
