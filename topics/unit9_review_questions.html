Review Questions and Applied Exercises

Attempt these independently, then use the notes and fictional catalogue to check your reasoning.

  1. Define metadata and explain why a useful description is more than a filename.
  2. Distinguish a resource, its intellectual item identifier and its file representation.
  3. Explain descriptive, structural, technical, administrative and preservation metadata.
  4. Give three descriptive fields for a video and three technical fields for an audio file.
  5. Why must a source master and a compressed access derivative remain linked?
  6. What does the term provenance mean in an archival catalogue?
  7. State five of the Dublin Core fifteen elements and provide appropriate values.
  8. Name all fifteen original Dublin Core elements.
  9. Distinguish the original Dublin Core element set from broader DCMI Metadata Terms.
  10. When might a Dublin Core description be insufficient for a complex record series?
  11. Explain the main roles of MARC 21, EAD, METS and PREMIS without treating them as equivalent.
  12. What type of information does PREMIS event metadata capture?
  13. Why do checksums not verify the truth of a description?
  14. Give a suitable local identifier for a photograph in a collection.
  15. Propose file names for a master and access copy of a four-page document.
  16. Explain the difference between a local identifier and a maintained persistent identifier.
  17. Draw a collection–series–item–file relationship model for a fictional archive.
  18. Explain how captions, OCR text and transcripts relate to a media item.
  19. What is a controlled vocabulary? Give an example of a preferred term and synonym.
  20. How can inconsistent creator names reduce retrieval quality?
  21. How would you represent a resource whose exact creation date is unknown?
  22. Why should you not automatically set the language of a photograph to English?
  23. Compare an identifier search, title search, all-field keyword search and faceted search.
  24. Give one reason a valid OCR file could return misleading keyword matches.
  25. A query returns 4 results, 3 relevant; 6 items in the collection are relevant. Calculate precision and recall.
  26. Identify four automated metadata checks that can be run on a CSV.
  27. Explain why a passed validator does not guarantee accurate or safe metadata.
  28. What is an application profile and why is it useful?
  29. How do CSV and JSON differ from a semantic metadata standard?
  30. How can metadata accidentally disclose private information?
  31. List the fields needed to describe a BLISS multimedia exhibition.
  32. Design a BRIM record description with series, provenance and controlled access.
  33. Search a sample collection and describe one way to improve precision or recall.
  34. Write a short metadata-QC correction log for a duplicate ID and missing title.
  35. Explain how a public discovery record can coexist with a restricted digital object.
  36. Describe a complete workflow for preparing a six-item multimedia catalogue.

How to answer

For definitions, explain the purpose as well as the term. For design tasks, name the item, fields and restrictions. For search metrics, show numerator, denominator, formula and percentage. For archive scenarios, preserve series context and authorisation.
