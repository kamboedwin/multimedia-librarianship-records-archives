LIU08106 / RIU08106 · Unit 07

Review Questions and Exercises

Use clear definitions, specific examples, diagrams where requested, and accountable professional reasoning.

Concepts and authoring

  1. Define multimedia authoring and explain how it differs from editing a single image or recording.
  2. What are hypertext and hypermedia? Give one relevant example of each.
  3. Distinguish a node, anchor and destination in a hypermedia system.
  4. Compare linear, non-linear and mixed navigation using a real information-service task.
  5. Explain the meaning and risks of broken links, dead ends and orphan pages.
  6. Identify five capabilities of a multimedia authoring environment.
  7. Why can a static website be an interactive multimedia resource?
  8. Distinguish the roles of HTML, CSS and JavaScript in a basic guide.

Planning and interface design

  1. Draw a five-screen sitemap for a library orientation with at least two return routes.
  2. Create a simple directed-link map and find an orphan page in your example.
  3. List eight fields for a storyboard or screen specification.
  4. Describe a user journey from arriving at a site to locating an archived item and checking its rights.
  5. Compare hyperlinks and action buttons. Why should their intended roles differ?
  6. Write three meaningful link labels to replace “Read more”, “Click here” and “More”.
  7. Explain the purpose of status feedback and recovery in an interactive system.
  8. Give four criteria for choosing between a presentation, website builder and static website.

Accessibility and usability

  1. Describe how to test a resource using only a keyboard.
  2. Explain the purpose of visible focus and a logical focus sequence.
  3. State the general WCAG 2.2 AA contrast rules for normal and qualifying large text.
  4. Explain what good alternative text should convey for an archival photograph.
  5. Why might a caption file and transcript be required for a video-based guide?
  6. Design three observable usability tasks for the five-screen prototype.
  7. Distinguish a checklist-based accessibility review from full WCAG conformance testing.
  8. Explain why colour alone should not indicate success or failure.

Professional and applied cases

  1. Propose five metadata fields and two rights checks for an interactive archival item.
  2. BLISS scenario: design a home-to-catalogue-search path with an accessible help option.
  3. BRIM scenario: design a route from an archive timeline to a fictional item and its provenance.
  4. Explain how a public exhibition can misrepresent a record when context is missing.
  5. List six steps for a website release checklist suitable for low-bandwidth learners.
  6. Prepare a test log with problem, severity, proposed repair and retest outcome.
  7. What should a final student submission include to demonstrate that a prototype really works?
  8. Write a reflection contrasting visual appearance with actual user-task completion.
Revision guidance: Prefer user-task evidence over unsupported claims of usability, and do not describe a classroom checklist as proof of full accessibility. These are formative questions rather than an official exam.
